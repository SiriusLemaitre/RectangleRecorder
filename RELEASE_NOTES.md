# Rectangle Recorder 1.4.1

- Added **Open folder** beside **Save recordings to** to open the selected recording folder in File Explorer.
- The folder is created automatically if it does not exist yet, so the button works before the first recording.

Download `RectangleRecorder-1.4.1-win-x64.zip`, extract all files into one folder, and run `RectangleRecorder.exe`. Requires Windows 11 x64; the .NET runtime and FFmpeg are included.

Validation: Release build succeeded with no warnings or errors. The portable app and native launcher were built successfully. Interactive folder opening has not been manually verified.
